# Quiz App

An interactive and responsive quiz application built using HTML, CSS, and JavaScript.

## Features

* 10 multiple-choice questions
* 15-second countdown timer for each question
* Instant correct and incorrect answer feedback
* Automatic score calculation
* Final score and percentage display
* Best score saved using localStorage
* Restart quiz functionality
* Responsive user interface

## Technologies Used

* HTML5
* CSS3
* JavaScript
* DOM Manipulation
* LocalStorage API

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser or use VS Code Live Server.
